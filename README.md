## 🎮 Ringkasan Permainan

**Eco Avengers** adalah permainan board game kooperatif (3-5 pemain) di mana seluruh pemain bekerja sama untuk menstabilkan krisis lingkungan di 5 benua (Afrika, Asia, Eropa, Amerika Utara, dan Amerika Latin).

### 👥 5 Peran Karakter Spesialis:
1. **Energy Scientist**: Mengurangi tingkat kesulitan krisis energi sebesar 1 poin.
2. **Ecologist**: Mengurangi tingkat kesulitan krisis degradasi lingkungan sebesar 1 poin.
3. **Environmental Activist**: Memiliki mobilitas tinggi (dapat melangkah 2 petak sekaligus).
4. **Policymaker**: Memberikan buff +1 hasil dadu untuk pemain kawan di sekitarnya.
5. **Climate Engineer**: Mengurangi tingkat kesulitan ketahanan iklim sebesar 1 poin.

### 🎲 Mekanisme Inti:
- **Token Sistem**: Energy Token, Peace Token, Crisis Token, dan Move Icon.
- **Kartu Aksi (Action Cards)**: Berbagai solusi lingkungan riil untuk mitigasi bencana iklim.
- **Kartu Krisis (Eco Crisis Cards)**: Skenario tantangan iklim acak di setiap benua.
- **Mode Permainan**: Single Player & Online Real-time Multiplayer (kode kamar 6 digit via Supabase).

## 🛠️ Prasyarat & Menjalankan Proyek

- **Flutter SDK**: ^3.10.8 atau lebih baru
- **Dart SDK**: Sesuai versi Flutter
- **Android Studio / VS Code** dengan ekstensi Flutter & Dart

### Perintah Instalasi:

```bash
# Mengambil seluruh dependencies
flutter pub get

# Menjalankan aplikasi di emulator atau device Android
flutter run

# Mengompilasi berkas APK rilis
flutter build apk --release
```

Berkas APK rilis akan tersimpan di:  
`build/app/outputs/flutter-apk/app-release.apk`
